ABOUT

Backend-first, full-stack when it counts.

I started out building static sites and WordPress platforms, then moved into Laravel and PHP because I wanted to own the whole system — the database, the business logic, and the API — not just the page you see.

Today I design MySQL schemas with Eloquent, wire up REST APIs and third-party services like Paystack, and write PHPUnit tests so the codebase stays reliable after I hand it over. I'm also growing my Node.js and Express skills, so I can take on projects that call for a JavaScript backend, not just PHP. I bring the same care to the front end, using React or Blade depending on what the project needs.

Most of my work has been remote, for real clients with real deadlines — invoicing platforms, community savings apps, cybersecurity firms, and engineering consultancies. I manage my own deployments, so nothing goes live without me watching it work.
